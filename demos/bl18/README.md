# BL18 市政府站地下商場與月台

[開啟可走動的導覽](https://forself.github.io/Lumiere/bl18/) · [可編輯的 Lumiere 建築模型](./bl18-building.json)

進場後沿商店街中央向前，經市府轉運站連通口、捷運大廳及驗票閘門，沿樓梯下到島式月台候車區。桌面使用 W 或上方向鍵前進、拖曳轉頭。支援 WebXR 的頭顯可用「進入 VR」切換為雙眼視角。獨立 HTML 內含模型與導覽程式。

模型以乘客動線為主，涵蓋往市府與統一國際大樓的連通道、統一時代百貨地下美食街、2 號出口、站內大廳及月台。官方資料提供各區的用途與連通關係。走廊長度、櫃位、垂直動線位置、色彩及樓高採用展示配置，店名為示意，實際旅程請依現場標示。
