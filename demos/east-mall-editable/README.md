# 忠孝復興站、東區地下街與街面模型

[從第二廣場走到街面](street-workshop.html#plaza-walk)。沿柱列前的通行帶走向 14 號出口。由地下往上看，左側電扶梯上行，踏上後鬆開 W 就會載人到雨棚平台。走下室外短階，便可沿人行道進入頂好廣場。回程從另一側電扶梯下樓。整段共用同一個步行場景。

站內另有 [B4 月台端至 B3 大廳端的上行電扶梯](street-workshop.html#b4-escalator)及可雙向行走的[固定樓梯](street-workshop.html#b3-stairs)。B3 至購物通道間的模型尚有斷點。北捷公布東區地下街全長 725 公尺、有 7 座廣場及 17 處出入口，本版未完成整條地下街及所有出入口的連續步行。[北捷東區地下街介紹](https://www.metro.taipei/cp.aspx?n=1DE23B423CA113D2&s=DEDB3C20E33C48E3)

## 桌面頭顯模擬與繪圖效能

本機開啟 [B3 樓梯端的 Quest 3 模擬](street-workshop.html?headset=quest3#b3-stairs) 或 [第二廣場與 14 號出口](street-workshop.html?headset=quest3#plaza-walk)，按「進入 VR」可看到並排的雙眼畫面。在站內步行時，控制列的「向前移動」與「向後移動」會沿目前朝向移動，按「退出模擬」可回到原頁。一般入口使用瀏覽器原生 WebXR。模擬器採 IWER 2.8.0，檔案與授權位於 simulator 子目錄。實體頭顯尚未驗收。

- 兩份 SHP 的座標系統為 TWD97 / TM2 zone 121（EPSG:3826），經與既有人行道相同的換算進入街區模型。選取與既有兩個工作範圍相交的完整多邊形，未裁切或抽稀輪廓。道路保留 4,753 個頂點，行穿線範圍保留 604 個頂點。圖層顏色用於辨識構件。
- 首次讀取道路 SHP 時遇到空幾何記錄，初次讀取行穿線 ZIP 時發現內含多個 SHP。匯入器改為略過無幾何記錄、逐層處理全部 6 個行穿線 SHP。納入的 352 個多邊形均通過有效性檢查，繪製的 4,653 個三角面按構件檢查面積，皆與其來源輪廓換算後面積相符（容差 0.00001 平方公尺）。
- Edge 透過 Lumiere 工坊入口與離線 HTML 均可開啟。實測各改一個路面、人行道、行穿線角點，復原、重新套用、另存 JSON、重新開檔及匯出獨立 HTML。逐項比對只有這三個角點變動。舊版街區 JSON 也可開啟。從路口啟動步行及 Quest 3 模擬雙眼 VR，完成進出測試，實體頭顯尚未驗收。

## 建物與街面貼地修正

原版將建物來源基底（3.8599～7.8699 公尺）與未指定高程的道路（零公尺）直接放在同一畫面，造成懸空。新版使用 2026 年版內政部 20 公尺 DTM 的臺北市圖幅，將 TWD97 網格取樣到本場景的東、南座標。地面、道路、人行道、行穿線與步行觀察點均採同一地形面。地形來源的 20 公尺解析度無法分辨路緣、台階或各店面的門檻。[內政部 DTM](https://data.gov.tw/dataset/178729)

建物維持水平基底和原始屋頂至基底的高度差，將原始基底對齊輪廓覆蓋範圍內的最低地形點。斜坡較高的一側可能遮住牆腳，這是貼地的顯示方式。資料內保留原始基底、目前基底與屋頂標高。5 個外殼的俯視投影與道路鋪面重疊逾 80%，其底部淨高未核實。預設線框、可獨立選取並切換實體檢視。

以 Edge 實際繪出的座標檢查 1,505 個外殼、19,816 個輪廓點、所有道路與人行道及行穿線的 69,863 個表面三角形，建物基底對地面頂點的最大正向空隙小於 0.000001 公尺。此數值檢查繪圖一致性，現場精度取決於各來源。另驗證匯出、存檔、重開、地面步行及模擬雙眼 VR。[人眼高度截圖](street-ground-level.jpg) · [驗證數值](ground-verification.json)

## VR 按鈕
