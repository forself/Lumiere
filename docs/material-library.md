# 在導覽中調整材質

1. 在導覽頁開啟「物件功能」，從場景或物件清單選取要調整的家具。
2. 選擇材質分類與材質，查看該物件是否允許套用。例如一般家具可更換表面，匯入的模型則保留其內嵌材質。僅限地板的材質要在設計器選取房間地板時使用。
3. 按「套用材質」，確認外觀，再以「復原」與「重做」比對。換材質只調整外觀，碰撞與通行設定獨立。
4. 要保存內建材質的選擇，匯出建築 JSON 即可保存材質 ID。若專案還有自訂貼圖或匯入資產，使用「另存完整專案」。

材質登錄資料在 `src/frontend/designer/material-library.js`，適用對象由 `material-application.js` 判斷。可執行 `node tests/material-selection.mjs` 檢查允許及拒絕套用的情境。場景讀取和交付流程見[導覽手冊](tour.md)。
