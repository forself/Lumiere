# 匯出獨立巡覽網頁

在 3D 實境導覽載入場景，調整到要交付的樓層與視角，從「功能」選「匯出獨立網頁」。用新視窗開啟下載的 HTML，核對場景、初始視角與平面圖。檔案可帶到另一臺電腦，或放到可供頭顯存取的 HTTPS 網站。

HTML 內嵌當時的導覽程式、樣式、頁面定義、專案資料與已封裝的素材。原網站更新後，已交付的檔案仍使用舊版程式，要取得 WebXR 功能請重新匯出。瀏覽器在本機檔案上提供的 XR 權限可能不同。進入、退出與故障排查見[頭顯操作步驟](tour.md#戴上頭顯進入與退出-vr)。

| 情境 | 處理方式 |
| --- | --- |
| 專案含 IFC 參考 | 先用完整專案另存原件，再於要交付的副本移除 IFC 並重新匯出。匯出程式會明確拒絕含 IFC 的網頁。 |
| 有本機工作階段影音或外部影片 | 這些媒體不隨網頁攜帶。交付前請在新視窗檢查實際內容。 |
| 修改了獨立網頁中的場景 | 另存 JSON 或完整專案以保存修改。要產生新版 HTML，請把修改後的資料載回網站並重新匯出。 |
| 找不到執行包或修改程式後仍見舊功能 | 在專案根目錄執行 `npm run build:standalone`，重新載入網站並匯出。 |

`npm run check:standalone` 會核對執行包來源、內嵌模組、匯出內容、初始視角還原與頭顯工作階段。離線驗收時，用新視窗直接開啟匯出的檔案並封鎖外部網路，確認仍能操作場景。
