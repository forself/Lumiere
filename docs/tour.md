# Lumiere 3D 實境導覽

用同一份設計巡覽空間、核對門窗與家具的位置，或匯出一個可單獨交付的網頁。第一次啟動專案請依[倉庫安裝說明](repository-setup.md)還原執行庫，再執行 `npm run dev`。

## 載入與巡覽

1. 在設計工坊開啟場景，按「3D實境導覽」帶入目前設計。也可以直接進入 `#/tour`，從「功能 → 載入場景」選擇建築 JSON（最多 10 MiB）或完整 `.lumiere` 專案（最多 128 MiB）。含有自訂貼圖或匯入模型的場景請使用完整專案。
2. 在「功能」選「自由走動」。用 WASD 或方向鍵移動、拖曳轉頭；在支援觸控的配置可使用畫面上的移動鍵。平面圖會顯示位置與方向。雙擊平面圖的可站立地坪可移到該處。
3. 按 Esc 離開自由走動，或選「環繞檢視」回到全景，再用拖曳旋轉與滾輪縮放。樓層缺少可站立的地坪時，仍可用環繞檢視查看模型。
4. 在「物件功能」選取門窗可切換開關。選取可編輯家具後可調整位置、尺寸或[材質](material-library.md)，按「套用調整」或「套用材質」。用「復原」和「重做」檢查變更。
5. 從工坊進入時，以「套用變更並離開」將修改帶回設計器。若要保留可重開的檔案，請用「匯出 JSON」或「另存完整專案」。返回工坊的交接資料放在記憶體，重新整理之前請先保存。

## 戴上頭顯進入與退出 VR

在支援 WebXR 的頭顯瀏覽器開啟頭顯可存取、受信任的 HTTPS 網址。開發電腦的預覽服務預設只監聽該電腦的 `127.0.0.1`。

| 操作 | 預期結果 |
| --- | --- |
| 載入場景，按「進入 VR」，允許空間追蹤 | 建立 `immersive-vr` 工作階段，以 `local-floor` 作為地面參考。從目前步行位置或所選樓層可站立的位置開始。 |
| 緩慢轉頭、左右移動頭部 | 左右眼各有一個視角，場景隨頭部位置與方向更新。 |
| 握壓控制器側鍵、用頭顯系統選單離開，或啟用頁面的「退出 VR」 | 沉浸式工作階段結束，原本的桌面視角與控制方式恢復。 |
| 拒絕權限，或在無相容裝置的瀏覽器按「進入 VR」 | 頁面顯示權限或連線提示，可繼續桌面巡覽。 |

## 交付獨立 HTML

在有場景的導覽頁選「功能 → 匯出獨立網頁」。新檔案內嵌該版導覽程式；要將頭顯功能提供給持有舊 HTML 的人，請重新匯出。交付前用新視窗開啟檔案，核對場景與視角，再測一次進入及退出 VR。各瀏覽器對本機檔案的 XR 權限不同，頭顯展示宜使用 HTTPS。[獨立網頁的內容與限制](standalone-web-export.md)

## 重跑驗證

在 Lumiere 根目錄依序執行：

```sh
npm run build:standalone
npm run check
npm run check:standalone
node tests/tour-layout.mjs
node tests/tour-page.mjs
node tests/tour-editing.mjs
node tests/tour-minimap-resize.mjs
node tests/tour-capability.mjs
```

裝置驗收要分別操作網站與新匯出的 HTML。記下頭顯型號、瀏覽器版本、兩眼成像、轉頭及平移、退出後能否再次進入。模擬器可驗證工作階段和渲染流程；佩戴舒適度與實機幀率需用實體頭顯量測。
